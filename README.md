# Rock Paper Scissors

A simple Rock-Paper-Scissors game played in the browser console using vanilla JavaScript.

## How to Play
- Enter one of the following choices:  
  `rock` , `paper` , `scissors`
- The computer randomly selects its choice.
- The result is displayed in the console.

## Game Logic
- Rock beats Scissors  
- Scissors beats Paper  
- Paper beats Rock  
- If both choose the same, it's a Draw.

## Technologies
- JavaScript (Vanilla JS)
- Runs in the browser console

## How to Run
1. Open the `index.html` file in your browser.
2. Open the browser console (F12 or Ctrl+Shift+I).
3. Follow the prompts and start playing.
